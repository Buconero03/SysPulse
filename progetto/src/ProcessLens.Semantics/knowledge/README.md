# ProcessLens Knowledge Base

Questa cartella contiene firme tecniche generiche. Non e' un catalogo di prodotti.

Principi:
- una DLL non basta automaticamente a determinare il ruolo;
- le firme assegnano punteggi a evidenze indipendenti;
- framework e ruolo sono valutati separatamente;
- le regole specifiche di un prodotto non sono necessarie per la classificazione base;
- una regola malformata viene ignorata senza impedire l'avvio di ProcessLens.

Le firme possono usare DLL/moduli caricati, command line, nome/metadati, path,
classi finestra, relazioni padre/figlio e socket osservate da Windows.
