# R15 → R16

Prima: cache ARP/ND nativa e cattura Wireshark opzionale; nessuna vista dei blocchi WFP o degli accessi di rete falliti.

Dopo: terza scheda Segnali Windows con lettura manuale del registro Security locale e dei criteri audit attuali, senza installazioni aggiuntive. API native per query, enumerazione, rendering XML e rilascio delle risorse. Campione di 15 minuti, cap di eventi/testo/attese, nessuna sottoscrizione continua.

Report neutro: evento osservato, direzione, endpoint, PID storico; errori e limiti espliciti. Nessuna certificazione di rete sicura, nessuna attribuzione di intrusione, nessun conteggio dei client del router da questi eventi.

Le acquisizioni esistenti, classificazione, Guardian, profiler e monitor RAM restano invariati. La sezione non cambia i criteri di sicurezza e non genera traffico.

40 nuove asserzioni portabili con API simulata; 161 asserzioni di regressione ripetute. Test WPF aggiunti e tutti i precedenti conservati; esecuzione Windows non disponibile qui. Delta reale di RAM non misurato.
